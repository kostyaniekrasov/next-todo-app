<h1 align="center">Welcome to Next Todo App 👋</h1>

> A simple and intuitive To-Do List application that allows users to add, edit, delete, and filter tasks efficiently. The app is built with React Query for state management and API interactions, ensuring smooth performance and real-time updates.


### ✨ [Demo](https://next-todo-app-xi-orcin.vercel.app/)

## Install

```sh
npm install
```

## Usage

```sh
npm run start
```
### ✅ Task Management
- **Add a Task** – Enter text in the input field and press **Enter**.
- **Edit a Task** – Double-click on a task to edit its title.
- **Save Changes** – Press **Enter** or click outside the input field.
- **Toggle Task Completion** – Click the **checkbox** to mark a task as completed.
- **Toggle All Tasks** – Click the **down arrow (❯)** to mark all tasks as completed/incomplete.
- **Delete a Task** – Click the **X button** or clear the text while editing.

### 🔍 Task Filtering
- **All** – Show all tasks.
- **Active** – Show only incomplete tasks.
- **Completed** – Show only completed tasks.
- **Clear Completed Tasks** – Click the **Clear completed** button to remove all completed tasks.
